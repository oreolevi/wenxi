# 文析手绘头像

20 款原创生成头像，用于账户菜单与头像选择器。图像通过 OpenAI 图像生成工具制作，经人工审阅后导出为 256 × 256、保留透明通道的 WebP；不含业务材料、第三方品牌徽标或真实人物照片。

风格保持奶油色圆脸、两个椭圆眼睛、圆润下巴和简洁平面色块。通过发型、发色、帽饰、发带和眼镜区分人物。原始生成图及风格预览保留在本机输出目录，不进入运行构建。

圆形账户容器按每张图的实际人物轮廓分别缩放、居中，使人物更接近圆框边缘，同时保留帽饰、盘发和长发的完整轮廓。显示参数在 `src/avatarLibrary.ts`，原始透明图像保持不变。

`manifest.json` 记录各款编号、名称和原图 SHA-256。`src/avatarLibrary.ts` 显式引用资源，Vite 将其内联进三个运行模式的单文件构建，无需外部图像服务。

编号 01～20 和目录顺序保持稳定。默认头像按姓名映射；用户手动选择仍使用原有浏览器存储键与数值范围，并扩展到 20 款。替换库的画风会更新旧选择对应的图案，不清空用户选择；以后新增款式只追加，不重排已有编号。
