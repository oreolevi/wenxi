# Manrope Medium

Source: https://github.com/google/fonts/tree/main/ofl/manrope

The bundled WOFF2 is a static weight 500 subset of Manrope, covering Basic Latin and non-breaking space. It is used only for the “Extract Anything” landing heading. Other interface fonts and the Chinese SVG wordmark are unchanged.

License: SIL Open Font License 1.1, preserved in Manrope-LICENSE.txt and embedded in the exported HTML. The font itself is bundled into the standalone HTML; no Google Fonts request is made at runtime.
