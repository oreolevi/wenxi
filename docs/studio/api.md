# API 接入

在“接口与版本”获取已发布版本的调用示例。以下地址用于本地环境，ID 和版本替换为实际值。

## 系统分工

前端负责业务页面上的材料上传、状态反馈、结果展示和异常提示。前端调用自己项目的后端，由后端调用文析接口，再把需要展示的字段和依据返回前端。

后端负责配置服务地址、服务或场景 ID、固定版本、超时和错误处理，检查材料与字段状态，再做数据库比对和业务审批。平台侧密钥和生产访问配置留在服务端。

原文高亮需将返回的来源文件、页码和定位信息映射至文档预览。仅返回提取值无法恢复原文位置。

## 服务接口

独立服务接口使用 multipart 上传单个 PDF 或图片。`file` 是材料文件，`version` 是已发布版本。

```bash
curl -X POST 'http://127.0.0.1:8768/api/extraction-profiles/YOUR_SERVICE_ID/execute' \
  -F 'version=1.0.0' \
  -F 'file=@invoice.pdf'
```

接口会根据已发布配置读取文字层或执行 OCR，再匹配版式和执行规则。构建时的 AI 配置助手不参与运行时提取。

ZIP 或多类材料整包使用场景接口。服务接口仅接收单个 PDF 或图片。

## 场景接口

场景接口用 `files` 接收多份文件或 ZIP，用 `version` 指定场景发布版本。场景内已经固定各项服务版本，无需每次重新描述需求。

```bash
curl -X POST 'http://127.0.0.1:8768/api/studio/scenes/YOUR_SCENE_ID/execute' \
  -F 'version=1.0.0' \
  -F 'files=@contract.pdf' \
  -F 'files=@invoice.pdf' \
  -F 'files=@declaration.pdf'
```

需要指定文件用途时，可以传 `assignments`，其格式为文件名到场景内服务引用 ID 的映射。此参数可选，默认自动匹配。引用 ID 从实际场景配置读取，与服务 ID 和中文显示名称不同。

## 响应与异常

后端应检查整体 `passed`，并检查 `items` 中每份材料的状态、字段及依据。场景还会返回 `missingTypes`、`issues` 和 `summary`，用于区分缺少材料、匹配歧义、数量超限和单份处理失败。

场景的 `data` 按场景内服务引用 ID 分组，同类多份结果保留为数组。场景内名称用于显示，当前不会自动成为 JSON 分组键。以“接口与版本”的实际返回结构示意为准，在自己的后端做业务字段映射。

部分失败时，先按本项目要求转人工核对或提示补传，不能只检查 HTTP 状态码。解析结果通过后，再进行数据库比对和业务审核。

## 性能验证

用电子 PDF、扫描件、旋转材料、多页文件和实际材料包分别调用。接口的 `totalElapsedMs` 用于观察服务端本次处理总耗时，客户端还需记录上传、网络和业务比对时间。

配置页样例预览和批量规则回放复用已识别结果，不能用于承诺生产响应时间。

## 版本升级与回退

修改服务规则后，重新核对、测试并发布新版本。直接调用服务的后端显式更换 `version`；引用该服务的场景，需要先更换服务版本、重新整包联调，再发布新的场景版本。

需要回退时，在原版本仍保留的前提下，让调用方重新指定原发布版本。保留每次接入使用的服务 ID、场景 ID 和版本号，便于追踪。

## 运行记录

服务和场景工作区均有“运行记录”，用于查看实际 API 调用。服务记录包括版本、状态和总耗时；场景记录包括版本、材料数量、耗时和通过状态。

单次调试与发布前测试用于验证配置。发布后接口调用的运行记录用于检查接入效果，两者不要混用。

## 接入环境

`127.0.0.1` 只供本机验证。生产接入需要提供实际服务地址，并完成部署、访问控制、资源容量和监控对接。当前模拟公开审核不能替代企业账号权限体系。
