# 场景编排

场景引用多项服务的固定版本，统一处理材料约束、组合调用和结果汇总。字段与版式在服务内配置。

场景按业务用途命名，如“企业对外付款”“费用报销票据整理”。说明包含材料在业务流程中的用途，以及结果交给哪个系统使用。

## 场景创建

进入“我的场景 → 新建场景”，默认使用“AI 辅助创建”，根据需求、Excel 和样例生成组合草稿。也可在顶部切换为“手动创建”，建立空场景后在“服务编排”中添加服务。

新增服务草稿完成校准、测试和发布后，场景引用其固定版本。

## 服务引用

每项服务引用包含以下配置：

- **场景内名称**：表示材料用途，如“采购合同”，不影响服务名称。
- **调用版本**：固定使用的已发布服务版本。
- **必须上传此类材料**：缺少时整包处理不通过。
- **允许同类材料有多份**：用于多张发票等输入。

字段调整通过“配置服务”完成。服务发布新版本后，场景需显式选择新版本并重新联调。

## 整包联调

进入“整包联调”，上传一笔业务的完整材料或 ZIP，点击“开始联调”。检查服务匹配、材料缺失、数量约束、字段取值及依据。

“材料用途”可指定文件交给哪项服务，默认自动匹配。指定用途仍需符合服务支持版式。

未知版式、匹配歧义、材料缺失、数量超限及单份失败均需处理，部分材料成功不代表整包通过。

## 场景发布

当前组合联调通过后，完成发布检查并确认发布。在“接口与版本”获取场景调用示例。

场景版本固定各项服务版本。场景中的服务仍可独立供其他项目调用。

## 业务审核边界

场景检查材料处理状态及已配置的材料约束。合同、发票金额与数据库的比对及放行审批，由接入业务系统执行。
