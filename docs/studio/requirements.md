# 需求与样例

配置服务前，明确输入材料、字段口径和验收范围。

## 需求定义

确认材料类别、已知版式、单次提交数量、必需材料和缺失处理方式。为各类材料定义字段名称、业务含义及输出格式。

例如，付款条件与付款进度可能对应不同内容，应明确提取范围并提供预期示例。复杂语义字段需验证能否形成稳定规则。

## 字段表

使用未加密的 `.xlsx`，按材料类别建立工作表。每行一个字段，推荐包含字段名称、提取要求、格式说明和示例值。

发票字段示例：

- **发票号码**：完整票号，文本类型，保留前导零。
- **开票日期**：票面开票日期，约定输出格式。
- **购买方名称**：企业全称，区分销售方。
- **价税合计**：含税合计，区分不含税金额与税额。

## 基准与测试样例

每个版式选取一份清晰、有代表性的文件作为基准样例，用于定位。相同版式的其他文件用于测试，共用规则。

字段位置、标签或布局变化时增加版式。测试样例应覆盖电子 PDF、扫描、旋转及多页等实际输入。多页材料需区分跨页文档和逐页独立票据。

上传格式及容量限制见[支持范围](../getting-started/scope.md)。

## 验收口径

字段准确性以核定答案或人工抽检为准。规则测试通过仅说明当前规则取值和格式检查通过。

耗时要求应明确是否包含上传、ZIP 展开、转正、OCR、规则执行与数据库比对，并以实际文件接口调用验证。
