# 服务配置

服务定义一类材料的输出字段和各版式的取值规则，支持独立发布与复用。

服务按解析能力命名，如“电子发票要素提取”“扫描发票基础信息提取”。说明包含支持的材料、输出字段和版式范围；样例来源通过原始文件名追溯。

## 新建服务

进入“文析 Studio → 我的服务 → 新建服务”，填写名称和说明，创建后上传基准样例。名称和说明可在创建时留空，发布前补齐可识别的服务名称。

AI 辅助创建生成的服务草稿可从场景内“配置服务”继续编辑。

## 版式与样例

在左侧选择版式，通过加号添加新版式。左侧更多菜单中的“样例管理”用于添加测试样例和维护关联版式。

同一服务共用字段名称、接口字段名、类型及必填属性；各版式分别保存位置和标签定位规则。仅填写内容变化的文件作为同版式样例。

多页材料可使用整份文档，或指定一页作为单张版式的基准。逐页发票与跨页合同应分别配置页面处理方式。

## 规则生成

**AI 辅助**：在“配置助手”中描述字段要求或上传字段表，检查新增、修改及定位建议后应用至草稿。

**人工配置**：在“规则配置 → 添加字段”定义字段并定位。更多菜单中的“仅导入 Excel 字段定义”可批量建立清单，导入后仍需完成定位。

两个入口编辑同一份草稿，可随时切换。助手建议应用后需人工核对，不直接形成发布版本。

## 字段校准

1. 选中字段，核对名称和样例取值。
2. 点击原文来源，检查页码与高亮。
3. 位置错误时点击“调整定位”，选取文字或框选区域。
4. 检查类型、必填属性和定位方式；标签定位需确认标签及取值方向。
5. 点击“确认此字段”。修改已确认规则后重新确认。

“已定位”表示存在取值位置，“已取值”表示当前样例可取出内容，业务含义仍需核对。含前导零的编号使用文本类型。

## 高级规则

“高级规则设置”提供接口字段名、清洗选项、数值坐标和规则 JSON。接口字段名应稳定且不重复。

修改共享字段定义后，检查其他版式；各版式的位置分别校准。

## 预处理

标题栏“设置”提供方向检测、倾斜校正和页面分组。原文更多菜单支持查看上传原图和重新处理样例。

调整页面几何处理策略后，重新处理基准样例、检查定位并测试。检测结果不确定时对照原图确认。

## 草稿保存

草稿自动保存，标题栏显示保存状态。保存失败时处理错误并重试。自动保存保留编辑内容，发布另行生成固定版本。

后续操作见[测试与发布](testing.md)。
