# 测试与发布

服务发布前，验证基准样例、新材料与多样例回放结果。

## 基准样例试提取

“规则配置 → 试提取”使用当前规则回放基准样例。点击结果检查原文位置，验证规则修改效果。

核对后确认已取值字段；未找到或异常项需调整规则。

## 单份调试

进入“单份调试”，选择版式，点击“调试当前版式”上传新材料，检查取值、状态及高亮。

“用基准样例回放”用于复查配置。验收应使用未参与定位的新材料。基准成功、新材料失败时，检查版式、偏移、方向及定位范围。

## 批量测试

进入“批量测试”，添加材料并点击“运行回放”。逐份检查失败项，修改规则后重新运行。

批量回放复用已识别文字和坐标。“规则回放 P95”不包含上传与重新 OCR，完整响应时间需另行调用 API 验证。

## 检查发布条件

点击标题栏“发布”打开检查。缺项包括无版式样例、无字段、字段未定位、规则待确认、当前配置未测试或已有失败的批量报告。

点击“去处理”定位缺项，完成后重新检查。每个版式均需通过当前配置的测试，规则变更后需复测。批量测试为建议验收项；当前配置已有失败报告时，需处理后发布。

## 固定版本发布

检查通过后，可填写发布说明并点击“确认发布”。在“接口与版本”的“接口接入”中选择已发布版本并复制调用示例；“版本记录”保留发布时间、发布说明、配置摘要和发布时的测试摘要。配置未变化时可直接查看已有接口。

字段、版式和预处理配置随版本固化，后续草稿修改不影响原版本。

## 公共服务库申请

服务版本发布后可调用 API。需要共享时，另行申请加入公共服务库。当前公开审核为模拟流程，与接口发布分开。

独立调用见[API 接入](api.md)，组合调用见[场景编排](scenes.md)。
