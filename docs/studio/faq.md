# 常见问题

## 服务与场景的创建顺序

单类材料直接创建服务。多类材料可先建立场景，或通过 AI 辅助创建生成服务拆分建议。两种入口使用相同的服务配置、测试和发布流程。

## 同版式文件的复用

相同版式、取值不同的文件作为多份样例共用规则。布局、标签或位置变化时再增加版式，在“样例管理”中维护关联。

## AI 规则的人工确认

人工确认用于校准取值、来源和可复用规则，不是对 OCR 模型逐份训练标注。AI 生成内容可能定位错误或缺少依据，需核对后应用。

## 字段确认不可用

检查读取状态、字段定位和样例取值。未定位、取值失败或规则异常时先完成调整。已确认字段不可重复确认，修改后需重新确认。

## 发布检查要求复测

检查针对当前配置。规则变更或存在未测试版式时，旧报告不能用于发布。点击“去处理”定位到相应版式或测试区。

## 回放耗时与接口耗时

规则回放复用已识别结果；新文件 API 还包含上传、预处理、OCR 和匹配等环节。生产响应时间以完整文件调用为准。

## 扫描件处理失败

检查清晰度、方向、倾斜、页面分组和文字识别结果。扫描件采用不同布局时，增加对应版式并测试。

## 多服务匹配冲突

检查版式特征，必要时在整包联调中指定材料用途。指定用途不能绕过版式校验，文件名也不能单独作为归类依据。

## 公共服务调整

字段与版式一致时引用固定版本；需要修改时复制为自己的服务，调整后测试发布。复制修改不影响原服务。

## 接口发布与公开申请

接口发布后可调用。加入公共服务库需另行申请指定版本，当前审核采用模拟流程。

## Skill 与能力组件配置

常规开发使用平台已有能力，无需预先配置 Skill 或能力组件。新增行业语义规则或底层处理能力由平台维护人员扩展。

## 解析通过与业务放行

解析通过表示规则取值及检查通过。业务系统仍需执行数据库比对、核验和审批。
