# 字段表导入

Excel 字段表用于定义提取范围和取值要求，与待处理 PDF 或图片一同提交。

## 字段表格式

使用未加密的 `.xlsx` 文件，每行一个字段。推荐列如下：

- **字段名称**：如“购买方名称”。
- **提取要求**：如“购买方企业全称，区分销售方”。
- **格式说明**：如“文本，按票面保留”。
- **示例值**：如“示例贸易有限公司”，仅说明预期格式。

具有业务歧义的字段应补充取值口径。例如，付款条件需说明提取付款前提、付款节点或两者。示例值不作为固定提取答案。

## 导入与检查

1. 添加字段表和待处理材料。
2. 读取完成后，点击“查看字段”。
3. 多工作表文件选择本次使用的工作表。
4. 核对字段数量、名称和说明后提交。

当前一次使用一份字段表。更换时移除原表后重新添加。

## 提交要求

> 按 Excel 中的字段和要求提取合同内容，并展示原文依据。

可在对话中补充材料范围或取值口径。结果核验方式与自然语言提取相同。

## Studio 字段导入

多类材料分别使用工作表，例如合同、发票和报关单。AI 辅助创建可据此生成服务拆分建议。

导入具体服务时，选择对应工作表。仅导入字段定义不会完成原文定位，后续需生成或配置规则、校准并测试。详见[服务配置](../studio/services.md)。
