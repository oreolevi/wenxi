# 产品概述

文析提供交互式文档解析和固定版式提取服务。解析结果包含字段值、来源页码和原文位置，支持人工核验与结构化导出。

## 文析

面向业务人员，通过自然语言或 Excel 定义提取要求，完成材料上传、结果核验和导出。

- [文档上传与提取](business/extraction.md)
- [字段表导入](business/excel.md)
- [结果核验与导出](business/review.md)
