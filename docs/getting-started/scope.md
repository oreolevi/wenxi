# 支持范围

当前版本的文件格式、容量限制、数据处理与接入范围。

## 文析

真实材料试用使用本机地址 `http://127.0.0.1:8768/`。支持 PDF 和图片；可用文字层的 PDF 优先读取原文，扫描件交给 MinerU。配置 DeepSeek 后，由它理解字段要求并组织结果。

Excel 的 `.xlsx` 文件作为字段要求。每次最多添加 6 份附件，字段表不超过 8 MB，其他文件每份不超过 30 MB。当前一次使用一份字段表。

TXT 支持本地文字行匹配和全文导出。PDF、图片支持 MinerU 全文转换；仅转换全文时不调用 DeepSeek。文析暂不支持 Word 转换和 ZIP 解包。Word 转为 PDF 后上传；ZIP 解压后添加 PDF 或图片。

内置示例使用固定演示材料与结果，适合体验交互。实际能力需要用真实附件验证。

## 文析 Studio

样例和材料包支持 PDF、PNG、JPEG、WebP、ZIP，字段表使用 `.xlsx`。每个上传文件不超过 30 MB，材料包每批最多展开 20 份材料、总计不超过 100 MB。每个服务最多保留 10 个版式和 50 份附加样例。

已支持规则配置、AI 辅助、测试、固定版本发布，以及场景组合和接口调用。固定规则适合已明确支持的版式，未知版式和复杂语义需求需要另行验证。

服务单文件 API 接收 PDF 或图片；多文件和 ZIP 整包调用使用场景 API。详见[API 接入](../studio/api.md)。

## AI 与材料数据

通用解析和配置助手使用 DeepSeek 时，识别文本与提取要求会由服务端发送至该接口。当前公共 API 试用使用虚构或已脱敏材料。

Studio 固定版本接口执行已发布的预处理配置与字段规则，运行时不调用配置助手。AI 生成的草稿需要核对取值、依据和可复用规则。

## 历史、运行记录和看板

个人文档解析结果及失败记录保存在历史记录中，字段与全文可重新打开，继续核验和导出。Studio 运行记录用于查看实际 API 调用，与配置时的测试分开。

运行看板可以切换实际数据与 Mock 数据，个人历史仅展示实际记录。示例统计不能用于判断真实处理量、业务准确率或生产性能。

## 共享和生产接入

服务发布与加入公共服务库是两个动作。当前公开申请及审核采用模拟流程，企业账号权限和生产环境访问控制需另行接入。

`127.0.0.1` 供本机验证。生产还需部署服务、验证容量并接入监控。数据库比对和审批由业务系统负责，解析结果不直接决定业务放行。
